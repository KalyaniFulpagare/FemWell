# FemWell

FemWell is an ML-powered PCOS risk screening and educational web application.

## Features

- User authentication
- Guided PCOS screening questionnaire
- Machine-learning based risk estimation
- SHAP-based explanation of model predictions
- Personalized result breakdown
- What-if analysis support
- Assessment history
- Non-diagnostic educational guidance

## Tech Stack

**Frontend**
- React
- Vite
- CSS

**Backend**
- Python
- FastAPI
- SQLite
- JWT Authentication

**Machine Learning**
- Python
- Scikit-learn
- CatBoost
